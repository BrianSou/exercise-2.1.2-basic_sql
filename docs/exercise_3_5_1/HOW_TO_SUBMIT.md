# Submitting Exercise 3.5.1

The PR files are ready, but you must submit them from your own Git repository.

```bash
git checkout -b feature/sprint3-logging-tests-review
git add .
git status
git commit -m "Add structured API errors, logging, and test evidence"
git push -u origin feature/sprint3-logging-tests-review
```

Check `git status` before committing. Never include `.env`, passwords or local secrets.

Create a pull request targeting `develop`. Use this title:

`[Consultant name] Perform Pull Request Code Review (Week 3)`

Copy `PR_DESCRIPTION.md` into the PR description. Use `REVIEW_CHECKLIST.md` for the review and `REVIEW_COMMENTS.md` as a starting point for discussion. Request a coach review and record actual review comments. Do not merge until blocking comments are resolved and the coach approves.

No Git PR or independent review has been created through this exercise package.
